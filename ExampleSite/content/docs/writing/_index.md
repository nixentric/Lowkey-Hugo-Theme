Everything you publish is a Markdown file in `content/`. This section shows what the theme does with those files.

1. [Posts and pages]({{< relref "posts" >}}): creating posts, front matter, images, summaries, the home page and standalone pages.
2. [Markdown & code]({{< relref "markdown" >}}): code highlighting, tables, footnotes, math, emoji and the table of contents.
3. [Shortcodes]({{< relref "shortcodes" >}}): alerts, captioned images and task lists.
4. [Categories and tags]({{< relref "taxonomies" >}}): grouping posts and customizing the overview pages.
5. [Documentation pages]({{< relref "documentation-pages" >}}): building docs like these, with a sidebar.
