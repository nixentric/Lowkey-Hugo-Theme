**Lowkey** is a clean and fast Hugo theme inspired by [Adam Wathan's blog](https://adamwathan.me/). It keeps the design quiet so your writing stands out, and it is styled with Tailwind CSS so it stays easy to change.

These docs are built with the theme's own documentation layout. The menu on the left (or the **Documentation menu** button on a phone) is generated from the `content/docs/` folder, with no extra configuration.

## Features at a glance

- **Readable by default:** one narrow column, generous spacing and the Inter typeface.
- **True black dark mode:** follows the visitor's system setting, has a toggle, and never flashes the wrong theme while a page loads.
- **Friendly dates:** new posts say "3 days ago" or "last month"; older ones show a full, localized date such as "August 3, 2026".
- **Documentation pages:** a sidebar built from your folders, ordered by `weight`, collapsing into a menu on phones.
- **Shortcodes:** alerts in four colors, captioned images and clean task lists.
- **Rich Markdown:** syntax highlighting, tables, footnotes, definition lists, math with MathJax and emoji.
- **Table of contents** for any page, turned on with one line of front matter.
- **Categories and tags** with post counts.
- **Comments** with giscus (GitHub Discussions) or Disqus.
- **SEO basics built in:** meta descriptions, canonical links, `robots.txt`, a sitemap, RSS feeds and Google Analytics 4.
- **Translations** for English, Portuguese and Indonesian, and an easy way to add your own.
- **Mobile friendly:** no sideways scrolling, even with long links or wide formulas.
- **Every template can be overridden** from your own site, so updates never wipe your changes.
